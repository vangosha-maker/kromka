# Кромка

«Кромка» — пошаговая тактика на поле 8×8: три меха защищают здания от врагов, чьи удары видны заранее. Главный приём — не урон, а толчок: сдвинутый враг бьёт туда, куда вы его повернули.

## Мехи

- **Клин** — удар и толчок
- **Дуга** — навесной выстрел с толчком соседей
- **Крюк** — притягивание

## Враги

- **Жук** — бьёт соседа
- **Игла** — луч на три клетки
- **Молот** — сильный удар рядом
- **Мортира** — навес ровно на три клетки поверх преград

## Правила коротко

- Продержитесь указанное число ходов. Энергия зданий на нуле или гибель всех мехов — поражение.
- Из разломов выходят подкрепления: на клетке видно, кто выйдет и через сколько ходов. Мех на разломе срывает выход ценой 1 урона.
- Если врагов не осталось и новых не будет, бой выигран досрочно.
- В каждом бою три звезды: продержаться, сберечь всю энергию, не оставить на поле врагов.

## Запуск

Откройте [`index.html`](index.html) в браузере или страницу GitHub Pages:

https://vangosha-maker.github.io/kromka/

Игра — один файл без зависимостей и сборки. Правила боя лежат в отдельном модуле без DOM (`KromkaLogic`), поэтому их можно гонять в Node для проверки баланса.
