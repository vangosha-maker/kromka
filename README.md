# Кромка

«Кромка» — пошаговая тактика на поле 8×8: три меха защищают здания от врагов, чьи удары видны заранее.

## Мехи

- **Клин** — удар и толчок
- **Дуга** — навесной выстрел с толчком соседей
- **Крюк** — притягивание

## Враги

- **Жук**
- **Игла**
- **Молот**

## Бои

1. **Обрыв** — обучение
2. **Двор**
3. **Котёл**
